## 目标表给搜集方的交接规则

输出普通 **UTF-8 CSV**（可用Excel打开），每表1至40行、不超过128000字节，支持BOM、逗号/引号转义。推荐固定8列表头：

```text
公司,岗位,地点,官方链接,来源,核实时间,有效状态,原因
```

必备表头为公司、岗位和官方链接；可留空链接并在原因中说明未找到。只收集公开岗位信息，用户真实意向表仅本地交接，不将个人资料、附件或凭据写入公开仓库。搜集方核实官方来源及实际岗位，不用第三方聚合页冒充最终申请入口；表中尚无链接或已关闭的行保留，不转回让用户手工查找。
