## 已实现的行为

- “资料与简历”选择PDF后自动在本机提取，生成现有profile的未确认草稿；一次核对接受/保留/略过，可修订候选。多邮箱保持歧义，不拆猜姓名、补造日期或整段经历；只要求当前必要信息。已确认字段默认保留，接受冲突项才明确替换，旧翻译不会残留。模式切换单独保留原资料，不把演示历史混入本人资料。
- 文字型PDF使用锁定PDF.js在独立本机worker解析，无模型API或第三方上传；15秒、30页和15万文字预算。扫描、损坏、加密、无可映射文字和缺依赖分别提示。不会改写原PDF字节、SHA或附件引用绑定。
- 当前申请的已观察缺项集中列出，保留原题/选项/来源/版本；一次保存整批，旧批次或任一无效答案整批拒绝。稳定个人事实按已知字段语义保存进原profile，其他问题明确选择仅本任务或限定本站当前岗位原题。未知控件仍需本人核实，不能凭标签猜选项。
- 保存稳定事实后仍要求核对本次申请的新资料版本；同任务已答内容保留，不再手抄。后续任务复用已确认稳定事实，动机、国家/工作许可/时间条件不跨岗位盲用。网页已有值不同时列为冲突，不静默覆盖。原答案库支持查看/修改/撤销，profile可编辑或移除字段。
- 新增[原目录升级步骤](../UPGRADE_001.md)和“补充运行依赖.cmd”。只覆盖程序源文件，保留`.runtime`、已有模块、浏览器和绝对附件路径；兼容依赖直接复用，缺项执行`npm install --include=optional --ignore-scripts`，禁止浏览器自动下载。实际检测PDF平台组件，optional安装失败不能误报准备完成。
